# 採購題庫練習（ProcQuiz）

「採購專業人員基礎訓練」測驗的線上練習網站。題目與答案取自工程會「採購法規題庫」官方下載檔，
解析取自一份第三方整理的 xlsx；本站為個人整理的練習工具，**不是官方網站**。

## 狀態

M1 轉檔可用，網站尚未開工；進度見 [目標路線圖.md](目標路線圖.md)。
測試：`python -m unittest discover -s tests` 18 條全綠（2026-10-02，本機 Python 3.11.9，需 openpyxl、pypdf）。

## 更新題庫

1. `python tools/fetch_official.py`：從政府電子採購網「採購法規題庫」下載全部題庫的 DOC 與 PDF，兩份都成功才覆蓋 `data/source/official.*`。
2. `python tools/convert.py`：核對後寫出 `data/questions/*.json`，並列出與上一版相比新增、刪除、改答案的題目。任何一項核對不過就中止且不寫檔。
3. 第三方解析出新版時，覆蓋 `data/source/true-false.xlsx`、`multiple-choice.xlsx` 再跑第 2 步。
4. 跑一次測試、看過 `git diff data/questions/` 後 commit。

## 正確度怎麼守

| 核對 | 守什麼 |
| --- | --- |
| 官方 RTF 與 PDF 逐題比對（編號, 答案） | 解析器讀錯題目或答案；兩份是同一次下載，對不上只會是解析錯 |
| 每個課程、每種題型編號 1–N 連號 | 漏讀或重複讀題目 |
| 答案只能是 O／X 或 1–4，選擇題必須拆得出四個選項 | 欄位錯位 |
| 同一題文重複出現時答案必須相同 | 官方題庫自相矛盾 |
| 解析只掛在 xlsx 題文與答案都和官方相同的題目上 | 第三方解析對到舊題或錯答案 |
| xlsx 逐課程核對目錄頁題數與 O 題數 | 解析來源本身不一致（已知一例：PQZ-01） |

## 題庫來源

| 來源 | 版本 | 是非題 | 選擇題 | 提供 |
| --- | --- | --- | --- | --- |
| 工程會「採購法規題庫」全部題庫（RTF＋PDF） | 資料產生日期 115/10/02 | 2,686 | 913 | 題目、答案、法條（是非 1,262 題、選擇 264 題有法條） |
| 「題庫解析」xlsx（第三方，非官方） | 115.7.23 | 2,686 | 913 | 解析（實際掛上：是非 1,143 題、選擇 720 題） |

官方頁面不標題庫版次，下載檔只有「資料產生日期」，即下載當天。兩個來源 2026-10-02 比對的差異：

1. 是非題 `tf-02-0332`：官方答案 X，xlsx 同題文為 O，以官方為準，該題不掛解析。
2. 選擇題 `mc-11-0033`：官方題文改成「勞務承攬採購」（xlsx 為「勞動派駐採購」），答案相同，因題文不同不掛解析。
3. 其餘差異只有全半形括號、全形數字與相容字，正規化後相同。
