「採購專業人員基礎訓練」測驗的線上練習網站。題目對應工程會「採購法規題庫」，目前資料取自一份附解析的 xlsx 整理檔（非官方原檔）；
本站為個人整理的練習工具，**不是官方網站**。

## 狀態

M1 轉檔可用，網站尚未開工；進度見 [目標路線圖.md](目標路線圖.md)。
測試：`python -m unittest discover -s tests` 11 條全綠（2026-10-02，本機 Python 3.11.9）。

## 更新題庫

1. 新版 xlsx 覆蓋 `data/source/true-false.xlsx`、`data/source/multiple-choice.xlsx`。
2. 執行 `python tools/convert.py`：逐課程核對目錄頁題數與 O／X 數、答案合法、選項拆得出四個、重複題答案一致，任何一項不過就中止且不寫檔。
3. 用 `git diff data/questions/` 看這一版改了哪幾題，再跑一次測試後 commit。
