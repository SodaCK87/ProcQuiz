# 重點字逐題微調指示

> 重點字第一輪（2026-10-03）：12 支子代理逐題微調規則標記並提出答案線索，產出在 `data/review/work/highlight/round1/`。以下是當時給子代理的原文，不改寫；文中的檢查腳本是當時的暫存檔，現行核對改跑 `python tools/review/highlight_check.py`。

你在幫「採購專業人員基礎訓練」練習網站微調題目上的重點字標記。網站在作答前，就會把題目裡的重點字用金色粗體標出來，字首加一顆星，目的是讓使用者讀題時一眼看到考點，記住出題陷阱。

規則式字詞表已經先自動標過一輪（每題的 `marks` 欄）。字詞表包括否定詞（不得、無須、非屬…）、全稱限定詞（一律、均、僅…）、數字門檻（以上、未達、逾、百分之八十、30日、5,000萬元…）。你的工作是逐題看，只針對需要修正的題目輸出修正。

## 每題欄位

`id` 題號、`answer` 官方答案（是非題 O／X，選擇題 1–4）、`stem` 題目、`options` 選擇題的選項、`marks` 規則目前標到的字（照出現順序，同一個字可能出現多次）。

## 兩種修正

1. `drop`：規則標錯、不是考點的字。例如「所有權」裡的「所有」、只是在描述情境而跟答案無關的數字、跟答案無關的「以上」。drop 裡的字串要跟 `marks` 裡的某一項完全相同。它會把題目裡**所有**同字的規則標記都拿掉，所以同一題裡同一個字有的該標、有的不該標時，就不要 drop。
2. `add`：補標漏掉的考點。
   1. 漏掉的陷阱字：題目考的正是「應」與「得」、「始得」、「即」、「須」、「得逕行」這類字的差別時，才補標，不要每個「應」都標。
   2. 答案線索：題目裡決定答案的那一小段，也就是記住它就能答對的關鍵。是非題答 X 的，標出錯在哪；答 O 的，標出關鍵條件；選擇題標出題幹裡跟正解選項呼應的關鍵詞。只有一個明確關鍵、而且能縮到 15 字以內時才標；講不出單一關鍵的題目就不標。每題最多一段。

## 硬性規定

1. add 的字串必須從 `stem` **原樣複製**，全形半形、標點、相容字都不能改，也不能跨越跟題目不同的文字。程式會檢查，對不上的整筆作廢。
2. 修正完的標記總數（規則標記扣掉 drop、加上 add）每題不超過 4 處；規則本身就標超過 4 處的題目，修正後不得比原本多，並優先用 drop 減到 4 處以內。標太多就失去重點，寧可少標。
3. 不改題目、不改答案、不評論題目對錯。
4. 不需要修正的題目不要輸出。
5. 選擇題的 `options` 不會標記，只有 `stem` 會，只能從 stem 取字。

## 輸出

把結果寫成 JSON 檔到指定路徑，格式如下，只放有修正的題目，沒有的鍵（add 或 drop）省略：

```json
{
  "tf-02-0503": { "add": ["為防止緊急事故的發生所採取的防範措施亦屬之"] },
  "tf-03-0010": { "drop": ["所有"] }
}
```

用 UTF-8 寫檔（用 Write 工具，不要用 shell heredoc）。寫完後跑下面這行自我檢查，它會列出對不上的項目，有的話修正後重跑，直到印出 `OK`：

```
node <檢查腳本路徑> <你的輸入檔> <你的輸出檔>
```

最後回報：輸入幾題、修正幾題、drop 幾項、add 幾項（其中答案線索幾項），再附 3 個你最沒把握的判斷。
