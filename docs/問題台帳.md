# 問題台帳

職責：每個缺陷一列，記編號、嚴重度、證據、狀態、修好後的量測。型別：查詢型，不設上限、不切檔，靠「狀態」欄過濾。

編號規則：`PQZ-` 加兩位流水號，依列序配發，一經配發永不重用；其他文件提到時只寫編號。
