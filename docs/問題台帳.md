# 問題台帳

職責：每個缺陷一列，記編號、嚴重度、證據、狀態、修好後的量測。型別：查詢型，不設上限、不切檔，靠「狀態」欄過濾。

編號規則：`PQZ-` 加兩位流水號，依列序配發，一經配發永不重用；其他文件提到時只寫編號。

狀態只有四種：

| 狀態 | 意思 | 進場條件 |
| --- | --- | --- |
| 🔴 開放 | 確認是缺陷，還沒修 | 有可重現的證據（現況輸出與應有輸出） |
| 🟡 待驗 | 改好了，還沒有測試守著 | 程式已改 |
| ✅ 已修 | 有探針守著，重跑會紅 | 做過陽性對照：把修正拿掉，那條探針真的變紅 |
| ⏸ 不修 | 確認存在但決定不動 | 寫明為什麼 |

| 編號 | 嚴重度 | 摘要 | 證據 | 狀態 | 修好後的量測 |
